Pour le déployer sur Coolify :
1. Configure le token Coolify dans ~/.openclaw/.env :
   COOLIFY_TOKEN=ton_token
   
2. Ou utilise cette commande directement :
   cd ~/Documents/App/tuto-openclaw-site
   docker build -t tuto-openclaw .
   # Puis push sur ton registry Coolify
